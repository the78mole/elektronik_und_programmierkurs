# Modul 7: Eigene Projekte entwickeln

**Zielgruppe:** Ab 6. Klasse  
**Dauer:** 1,5 Stunden (oder mehrere Sitzungen)  
**Schwierigkeitsgrad:** ⭐⭐⭐⭐⭐ Projekt-basiert

## 🎯 Lernziele

- Eigenständig Projektideen entwickeln
- Planung von Hardware und Software
- Probleme selbstständig lösen
- Im Team arbeiten und kommunizieren
- Projekte präsentieren und dokumentieren

## 💡 Modul-Konzept

Dieses Modul ist anders als die vorherigen:
- **Keine feste Anleitung** → Ihr entscheidet!
- **Eigene Ideen verwirklichen**
- **Betreuer als Coaches**
- **Learning by Doing**

## 📋 Projekt-Ablauf

### Phase 1: Ideenfindung (20 Min.)

**Brainstorming:**
- Was möchtest du bauen?
- Welches Problem willst du lösen?
- Was wäre cool zu haben?

**Inspiration:**
- Schau dir bisherige Projekte an
- Kombiniere gelernte Techniken
- Denk an Alltags-Probleme

**Team-Bildung:**
- 2-3 Kinder pro Projekt
- Ähnliche Interessen
- Unterschiedliche Fähigkeiten (einer gut in Hardware, einer in Software)

### Phase 2: Projektplanung (20 Min.)

**Projektskizze erstellen:**
- Was soll das Projekt können?
- Welche Bauteile werden benötigt?
- Wie wird es programmiert?
- Wie könnte es aussehen?

**Checkliste:**
- [ ] Projektname
- [ ] Beschreibung (3-5 Sätze)
- [ ] Benötigte Sensoren
- [ ] Benötigte Aktoren (LEDs, Motoren, etc.)
- [ ] Besondere Herausforderungen
- [ ] Skizze/Zeichnung

**Betreuer-Check:**
- Ist das Projekt machbar (Zeit, Material)?
- Welche Hilfe wird benötigt?
- Gibt es ähnliche Beispiele?

### Phase 3: Prototyp bauen (40 Min.)

**Schritt für Schritt:**
1. **Hardware aufbauen**
   - Steckbrett-Aufbau
   - Komponenten verbinden
   - Erst testen, dann permanent bauen

2. **Software schreiben**
   - Erst einfache Version
   - Testen, testen, testen
   - Schritt für Schritt erweitern

3. **Iteration**
   - Was funktioniert?
   - Was muss geändert werden?
   - Neue Ideen einbauen

**Tipps:**
- Fange klein an!
- Teste jeden Schritt einzeln
- Nutze Serial Monitor zum Debuggen
- Frag Betreuer bei Problemen

### Phase 4: Verfeinerung (20 Min.)

**Verbesserungen:**
- Code optimieren
- Gehäuse bauen (Karton, 3D-Druck)
- Beschriftung hinzufügen
- Design verbessern

**Extras:**
- Mehrere Funktionen hinzufügen
- Alternative Steuerungen
- Sound-Effekte
- LED-Anzeigen

### Phase 5: Präsentation (15 Min.)

**Vorbereitung:**
- Kurze Demo überlegen
- Was war die größte Herausforderung?
- Was habt ihr gelernt?

**Präsentations-Struktur:**
1. Projektname und Team
2. Was macht das Projekt?
3. Kurze Demo
4. Besondere Features
5. Herausforderungen und Lösungen
6. Nächste Schritte (was würdet ihr noch ergänzen?)

### Phase 6: Dokumentation (15 Min.)

**Was dokumentieren:**
- Fotos vom Projekt
- Schaltplan (Skizze)
- Code-Listing
- Verwendete Materialien
- Probleme und Lösungen

## 🎯 Projekt-Ideen Katalog

### Kategorie: Smart Home

**1. Automatisches Nachtlicht**
- Sensoren: LDR (Lichtsensor)
- Aktoren: LED
- Level: ⭐⭐ Anfänger
- Beschreibung: LED schaltet bei Dunkelheit automatisch ein

**2. Temperatur-Überwachung**
- Sensoren: TMP36 (Temperatur)
- Aktoren: LED (rot/grün), Summer
- Level: ⭐⭐ Anfänger
- Beschreibung: Alarm bei zu hoher/niedriger Temperatur

**3. Pflanzen-Gießerinnerung**
- Sensoren: Feuchtigkeitssensor
- Aktoren: LED, Summer
- Level: ⭐⭐⭐ Mittel
- Beschreibung: Erinnert, wenn Pflanze Wasser braucht

### Kategorie: Robotik

**4. Hindernis-Vermeider**
- Sensoren: Ultraschall (HC-SR04)
- Aktoren: 2x DC-Motoren
- Level: ⭐⭐⭐⭐ Fortgeschritten
- Beschreibung: Roboter fährt und weicht Hindernissen aus

**5. Linienfolger**
- Sensoren: 2x Infrarot-Sensor
- Aktoren: 2x DC-Motoren
- Level: ⭐⭐⭐⭐ Fortgeschritten
- Beschreibung: Roboter folgt schwarzer Linie

**6. Servo-Roboterarm**
- Sensoren: Potentiometer (3x)
- Aktoren: 3x Servo-Motoren
- Level: ⭐⭐⭐ Mittel
- Beschreibung: Steuerbarer Roboterarm

### Kategorie: Spiele & Fun

**7. Reaktionsspiel**
- Sensoren: Drucktaster
- Aktoren: LEDs verschiedene Farben
- Level: ⭐⭐ Anfänger
- Beschreibung: Drücke die Taste, wenn die richtige LED leuchtet

**8. Quiz-Buzzer**
- Sensoren: 4x Drucktaster
- Aktoren: 4x LEDs, Summer
- Level: ⭐⭐ Anfänger
- Beschreibung: Wer zuerst drückt, gewinnt

**9. Elektronischer Würfel**
- Sensoren: Drucktaster
- Aktoren: 6-7 LEDs (Würfel-Muster)
- Level: ⭐⭐ Anfänger
- Beschreibung: Zeigt zufällige Zahl wie ein Würfel

### Kategorie: Messgeräte

**10. Entfernungsmesser**
- Sensoren: Ultraschall (HC-SR04)
- Aktoren: LEDs (Balken-Anzeige)
- Level: ⭐⭐⭐ Mittel
- Beschreibung: Zeigt Entfernung mit LEDs an

**11. Lautstärke-Anzeige**
- Sensoren: Mikrofon-Modul
- Aktoren: LED-Kette
- Level: ⭐⭐⭐ Mittel
- Beschreibung: Visualisiert Lautstärke

**12. Wetterstation**
- Sensoren: Temperatur, Luftfeuchtigkeit (DHT11)
- Aktoren: LCD-Display
- Level: ⭐⭐⭐⭐ Fortgeschritten
- Beschreibung: Zeigt Wetterdaten an

### Kategorie: Kunst & Kreativ

**13. LED-Lauflicht**
- Sensoren: Keiner (oder Potentiometer für Geschwindigkeit)
- Aktoren: 8-10 LEDs
- Level: ⭐⭐ Anfänger
- Beschreibung: Animierte LED-Muster

**14. Musik-Box**
- Sensoren: Drucktaster (8x)
- Aktoren: Buzzer
- Level: ⭐⭐⭐ Mittel
- Beschreibung: Spiel einfache Melodien

**15. LED-Matrix Display**
- Sensoren: Optional Sensoren
- Aktoren: LED-Matrix 8x8
- Level: ⭐⭐⭐⭐ Fortgeschritten
- Beschreibung: Zeigt Texte und Animationen

## 💡 Tipps für Betreuer

### Vorbereitung
- Material-Stationen aufbauen
- Beispiel-Projekte bereithalten
- Hilfs-Karten mit Schaltplänen vorbereiten

### Während des Projekts

**Als Coach agieren:**
- Nicht vorführen, sondern anleiten
- Fragen stellen statt Antworten geben
- "Was hast du schon versucht?"
- "Was könnte das Problem sein?"

**Unterstützung bei:**
- Ideenfindung (zu kompliziert/zu einfach)
- Fehlersuche (systematisches Debuggen)
- Code-Problemen (Syntax, Logik)
- Hardware-Problemen (Verkabelung)

**Zeit-Management:**
- Rechtzeitig an Präsentation erinnern
- Ggf. Projekt für nächste Sitzung fortsetzen

### Häufige Probleme

**"Wir wissen nicht, was wir bauen sollen"**
- Zeige Beispiele
- Frag nach Interessen
- Kombiniere Ideen von verschiedenen Kindern

**"Es funktioniert nicht"**
- Systematisch debuggen
- Teil für Teil testen
- Serial Monitor nutzen
- Zurück zu funktionierendem Stand

**"Wir sind fertig, was jetzt?"**
- Erweitere das Projekt
- Füge mehr Sensoren hinzu
- Verbessere das Design
- Hilf anderen Teams
